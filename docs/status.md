# StarLite 当前状态

更新于 2026-10-15。[0.1.0-alpha.1 已公开发行](https://github.com/StarCried/starlite/releases/tag/v0.1.0-alpha.1)，五个程序包已发布到 npm。安装时显式使用 `@alpha` 或完整版本号。发行源码固定为 `a103ca9`，运行时基线为 `986443cc`；发布后的文档更新不改变该 tag 或程序产物。

## 已实现

- 公共播放契约、取消旧加载、动作完成／中断结果、共享气泡和语句调度。
- VRM0／1、标准人形骨骼检查、限角光标跟随。当前本地候选将 Blink 改为可选能力，缺失时仍可使用；已声明的损坏绑定仍拒绝。
- 唯一内置 `StarLiteIdle`；无动作模型可使用基础站姿和轻呼吸，有自己的 `Idle` 时优先采用。
- 内嵌 glTF 动作自动识别、外部 VRMA、动作随机池和逐动作句库。气泡可不带动作。
- Hexo 直接读取单 VRM 文件并生成哈希资源，无需自定义 ZIP；高级用户仍可准备外部动作清单目录。
- 移动端默认零模型请求、正文优先启动、PJAX 单实例、首次入场去重和点击穿透。博客加载／渲染失败时隐藏角色并有限重试，成功后自动恢复；此项为发布后的本地修改，尚未发行。
- StarLite for DSH 的 Windows 桌宠、模型库和 DSH 应用事件由独立的 `starlite-dsh` 仓库维护；当前 DSH 禁用 Inochi2D。

模型、其他动作和角色源工程不进入程序包。默认 Idle 的来源、许可和导出记录独立保留；技术检查不代替资产授权。

## 本轮本地验收

2026-10-15 的当前源码候选已通过完整 `npm run validate`：Rust 26 项、JavaScript 与 demo 349 项通过，7 项外部模型测试跳过；实际 Chromium 14 项通过、2 项外部模型测试跳过。新增验收直接移除 VRM0／1 的可选表达数据，确认仍显示模型、使用内置 Idle，且角色下层链接可实际点击。Hexo 最简配置默认穿透页面输入；明确启用拖动时保留交互。角色配置的默认动作按完整动作目录在生成时校验，不再等浏览器加载后才发现名称错误。错误模型或配置路径会在依赖安装和构建之前给出修正提示。以上本地修改尚未发布；较早发行版的结果继续保留下方原身份。

已发行版本的单 VRM Hexo 路径完成单元与实际 Chromium 回归：无动作模型获得内置 Idle、纯文字气泡正常、20 次 PJAX 无重复实例、只请求一次模型、手机不请求 VRM／动作／运行时、加载失败出现静态占位。当前本地版本将博客静态占位改为隐藏和有限重试；验收应以新行为为准。单文件体验入口验证精确模型副本、损坏与符号链接拒绝、临时站点清理及保留另一个后端的构建产物。

隐藏与重试的本地浏览器回归已验证运行时导入失败、模型下载失败和运行中 WebGL 上下文丢失后的恢复：下层链接可实际点击，成功后只保留一个画布，已完成的首次入场不重复。离线／隐藏暂停、三次上限、PJAX 共用预算和迟到实例清理有自动覆盖。用户已在本地故障验收页确认：首次模型请求失败时无静态图片、随后自动恢复微光，恢复前后下层按钮均可正常点击。运行中上下文丢失等其余异常分支仅记自动覆盖，不冒充人工验收。本项修复尚未推送、发布或部署。

2026-10-14 的运行时基线 `986443cc` 已完成完整 `npm run validate`：Rust 26 项、JavaScript 与 demo 296 项通过，7 项依赖外部真实模型的测试跳过；浏览器 11 项通过、2 项外部模型测试跳过。两种后端构建、lint、typecheck、许可、预算与五包内容检查均通过。共享运行时代码变化后，DSH 必须更新固定 revision 并重建；文档更新不改变运行时基线。自动回归不代替目标设备的视觉与性能验收。

## 使用边界

- `inochi2d-blog` 的原生 CLI 为未签名的实验性 alpha；跨设备性能和用户视觉验收只按实际完成情况记录。
- Hexo 7 是当前验收目标，Hexo 8 尚未单独验收。浏览器目标为桌面 Chrome／Edge、WebGL2。
- 公开本地模型预算为 10 MiB；本机隔离 demo 可验证最多 64 MiB，不能把其预览输出用于部署。
- 外部动作在 ready 前准备好，尚未按需加载。Hexo 插件的安装依赖包含两个后端；浏览器只加载选中的后端。
- 微光从[独立模型发行](https://github.com/StarCried/starlite/releases/tag/weiguang-v3.0.0-starlite.1)取得并遵守随附许可。程序包不含模型，也不会替使用者授予其他资产的托管权。

详细检查及较早的 Inochi2D 与博客数据见 [validation](validation.md)。历史记录保留当时的身份与结果，不作为当前版本的安装输入。
