# StarLite 当前状态

更新于 2026-10-14。版本为 `0.1.0-alpha.1` 本地候选，尚未公开发布；本轮不 push、不发布 npm／GitHub Release，也不部署博客。

## 已实现

- 公共播放契约、取消旧加载、动作完成／中断结果、共享气泡和语句调度。
- VRM0／1、标准人形骨骼检查、可用 Blink 绑定检查、限角光标跟随。
- 唯一内置 `StarLiteIdle`；无动作模型可使用基础站姿和轻呼吸，有自己的 `Idle` 时优先采用。
- 内嵌 glTF 动作自动识别、外部 VRMA、动作随机池和逐动作句库。气泡可不带动作。
- Hexo 直接读取单 VRM 文件并生成哈希资源，无需自定义 ZIP；高级用户仍可准备外部动作清单目录。
- 移动端默认零模型请求、正文优先启动、PJAX 单实例、首次入场去重、点击穿透和静态占位。
- StarLite for DSH 的 Windows 桌宠、模型库和 DSH 应用事件由独立的 `starlite-dsh` 仓库维护；当前 DSH 禁用 Inochi2D。

模型、其他动作和角色源工程不进入程序包。默认 Idle 的来源、许可和导出记录独立保留；技术检查不代替资产授权。

## 本轮本地验收

单 VRM Hexo 路径已有单元与实际 Chromium 回归：无动作模型获得内置 Idle、纯文字气泡正常、20 次 PJAX 无重复实例、只请求一次模型、手机不请求 VRM／动作／运行时、加载失败出现静态占位。单文件体验入口验证精确模型副本、损坏与符号链接拒绝、临时站点清理及保留另一个后端的构建产物。

完整构建、包内容检查和 npm 候选安装以当前执行记录为准；共享源码变化后，DSH 必须更新固定 revision 并重建，不使用旧二进制冒充本轮候选。用户还需审阅新 README／配置，并手动确认真实模型效果；自动测试通过不代替该验收。

## 发布边界

- 公开 npm 发布后，还需从公共 registry 复测安装；本地 tarball 或临时 registry 成功不等于公共发布成功。
- 托管 CI、Windows 签名、跨设备长期性能和用户手动视觉验收只按实际完成情况记录。
- Hexo 7 是当前验收目标，Hexo 8 尚未单独验收。浏览器目标为桌面 Chrome／Edge、WebGL2。
- 公开本地模型预算为 8 MiB；本机隔离 demo 可验证最多 64 MiB，不能把其预览输出用于部署。
- 外部动作在 ready 前准备好，尚未按需加载。VRM 安装依赖目前仍包含可选 Inochi2D 后端；浏览器只加载选中的后端。
- 微光单 VRM 独立授权与分发，公开下载地址及资源上传须另行确认。源码或本地博客可运行，不表示模型已经公开分发。

较早的 Inochi2D 与博客数据见 [validation](validation.md)，它们是历史记录，不代表当前所有发布门已经通过。
