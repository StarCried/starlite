# 2026-10-19 本地稳定化验收

本页记录 `0.1.0-alpha.3` 发布前的本地稳定化检查。版本元数据现已准备，托管 CI、npm／GitHub 发行与公开安装证据在实际完成后另记于 [validation](validation.md)，不把本地检查当作已发布证明。用户安装见 [发行指南](release-guide.md)。

## 已完成

| 可做的优化 | VRM 诊断历史改为固定环形缓存；仅在读取诊断时计算投影统计。保留抗锯齿、动作、物理、画质和默认帧率。采样微基准不被宣传为整体 FPS 提升。 |
| 具体导入提示 | 检查器给出受控错误代码、缺失／无效／重复人形骨骼名和修复方向，不回显输入 URI。报告可用眨眼、头眼视线、动作和逻辑资源统计；保留资源与导入安全限制。 |

| 维护与反馈 | 修正支持范围和安全报告入口，增加问题模板、升级说明、Unreleased 记录、每周和 PR 的完整依赖扫描；新增问题、范围变化、过期例外及扫描失败均阻止检查通过。 |

检查实际发现并修复了一键体验仍使用旧注入入口、Inochi2D 分发模块出现裸包引用两项集成问题；不是仅运行单元测试后宣布通过。Windows 浏览器工作流已通过本地等价环境和 Actionlint，云端作业要等得到推送授权后才能运行。

## 测量结论的边界

RTX 5080 上，固定微光博客场景持续 923.9 秒、27,717 帧，约 30.00 FPS；20 次加载销毁后无存活旧画布或 WebGL 上下文。独立 60 FPS 测试为 60.04 FPS。

整套隔离 Chrome 的私有内存采样峰值约 800 MiB，包含浏览器和驱动缓存；不能称为低 RAM 产品。长测未出现持续增长，但这不是任意模型、设备或无限期运行的保证。贴图像素解码内存不等于文件大小或 accessor 逻辑数据量，集显、笔记本功耗和更多用户设备仍需实际反馈。

依赖扫描保留两个暂无上游补丁的 Hexo 链公告，共 9 个受影响包条目，不能声称零漏洞。[明确范围、影响和复核政策](dependency-audit.md) 将这两项限定为到 2026-11-18 的临时决定；不降级 Hexo、不隐藏原始扫描结果。

原始本地证据位于忽略目录 `target/maturity-validation/`、`target/hexo-default-qualification/` 和 `target/dependency-audit/`，不将私有模型、原始会话或机器用户信息提交到文档。DSH 的原生、安装和 Host 检查分别记录于其仓库的 `docs/stabilization.md`。
