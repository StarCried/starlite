# Validation

Run the affected package checks during development. The [release guide](releasing.md) defines the complete candidate checks and publication verification; [development](development.md) describes the local toolchain.

Release commands write machine-readable results beside their artifacts. Keep source revisions, artifact hashes and the checks actually run together. Device-specific visual, DPI, sleep and long-running measurements remain separate acceptance evidence; a later successful unit test does not renew those measurements.

## Historical evidence

The records below preserve their original versions and limitations. They are not commands for a new release. New evidence belongs with that release's CI artifacts and release report rather than being appended here.
